# CSS support

Status: `v0` = planned for the first release, `later` = planned, `no` = not planned.

| Area | Feature | Status |
|---|---|---|
| Selectors | type, class, id, descendant, child, `:first-child` | v0 |
| Selectors | `:nth-child`, attribute selectors | later |
| Selectors | interactive pseudo-classes (`:hover`, ...) | no |
| Box | `margin`, `padding`, `border`, `background`, `width` | v0 |
| Box | `border-radius` | later |
| Box | `position`, `z-index` | no |
| Text | `font-*`, `color`, `line-height`, `text-align`, `word-break: keep-all` | v0 |
| Text | `text-decoration`, `letter-spacing` | later |
| Layout | `display: block / inline / table` | v0 |
| Layout | `flex`, `grid` | later |
| Layout | `float` | no |
| Pages | `@page` `size` and `margin`, `break-before`, `break-after` | v0 |
| Pages | margin boxes (`@top-center`, ...) | later |
| Generated content | `::before`, `::after`, `counter()` | v0 |
| Generated content | `string-set` (running headers) | later |
