# 안녕하세요, Typemark입니다 {.cover}

Typemark는 브라우저 없이 Markdown과 CSS를 조판해서 PDF로 만드는 엔진입니다. 이 문단은 줄바꿈을 확인하기 위해 일부러 길게 작성했습니다. 한국어는 어절 단위로 줄을 나누기 때문에, 단어 중간에서 줄이 끊기지 않아야 합니다. English words like typesetting, pagination and shaping should wrap at spaces as well.

줄바꿈은 입력한 그대로 반영됩니다.
백슬래시 없이도 이 줄은 새 줄에서 시작합니다.

## 지원하는 요소

- 제목과 문단
- 순서 없는 목록과 순서 있는 목록
- 코드 블록과 `\pagebreak`

1. 첫 번째
2. 두 번째

```
fn main() {
    println!("안녕하세요");
}
```
